how to run the api in development mode:
1. open the terminal in the backend folder
2. start the backend API, run the following command in terminal: 
    > (.venv) PS C:\Users\linma\workspace\02-learning-AI\api\user-management\backend> fastapi dev src/api/main.py
3. you can access the API docs at http://localhost:8000/docs
4. health check endpoint at http://localhost:8000/health
